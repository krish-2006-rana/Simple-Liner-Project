# Simple Linear Regression Project

A foundational Machine Learning project implementing **Simple Linear Regression** to predict a continuous target variable based on a single independent feature.

## 📌 Overview
This repository contains a step-by-step implementation of Simple Linear Regression. The goal is to establish a linear relationship between an input feature (e.g., Years of Experience) and an output variable (e.g., Salary) using the equation:

$$y = mx + c$$

Where:
- $y$ is the predicted output (dependent variable).
- $x$ is the input feature (independent variable).
- $m$ is the slope (weight).
- $c$ is the y-intercept (bias).
